# Constraints (stage 0 — fixed 2026-08-25)

- **Time:** 10 hours/week (in parallel with the day job).
- **Money:** $50 max per experiment.
- **Kill deadline:** 4 weeks per idea to first signal, or it dies.

## Infrastructure defaults
- **Hosting:** GitHub Pages — free, fits the $50 budget.
- **Domain:** buy one domain (~$10–12/yr) for a professional look; use
  subdomains/paths per experiment so one domain serves all of them instead of
  buying a new one per idea.
